# DOE-MCP review, 2026-11-21

The shared core and domain servers remain a sound design. Activation gates,
recorded publisher responses and explicit coverage are useful constraints.
The review found defects in credential handling, catalog coverage and
composite retrieval metadata. The repairs preserve the public tool names.

This review covers every PR returned by the repository's all-state PR list,
the current implementations, skill benches, dependency advisories and the
public site's interactions. It does not certify the absence of vulnerabilities
or measure scientific answer accuracy. The Cloudflare security-audit skill
informed a focused source review; its formal full-audit workflow did not run.

## Repairs and usability

Credential files are prepared with private permissions before atomic
replacement. Credential input rejects whitespace and multiline assignments;
argument errors do not echo unknown names or values. Client configuration
updates preserve valid existing settings and use atomic backups and writes.

The HTTP fetch path redacts known credential values from errors and returned
request URLs. Its request-log filter removes query strings from the HTTPX
request log during DOE-MCP calls. This does not claim to sanitize arbitrary
third-party diagnostic logging. Redirects preserve publisher-supplied query
parameters, and malformed authorities fail through a typed error.

An entirely blocked catalog search now raises the activation error. Partial
searches retain their gaps. Pagination reflects each publisher's total,
including unknown totals, and a failed catalog cannot justify a no-match
claim. System status and planned outages now carry separate retrieval and
cache metadata.

The homepage adds walkthrough search with a result count and empty state.
Without JavaScript, all walkthrough links remain available. A skip link and
main landmark support keyboard navigation; section links move focus to their
destination. Invalid fragments no longer raise an uncaught error, and motion
respects the reader's preference. The field-atlas colors and typography stay.

GCAM source descriptions now list the existing tables, their callable tools,
exact filter columns and registered publisher files. This is explicitly local
catalog metadata, not a fresh read or a claim that a proposed source is active.
Units remain in publisher notes where the manifest does not establish them.

Optional evaluation tasks now cover region conventions, blank coefficients,
incompatible units and requests to treat model inputs as observations. They
prepare recorded tool environments and human grading rubrics. No paid model
comparison or human answer grading was performed in this review.

## Security scope

The previous MCP and Pydantic pins match published affected-version ranges.
MCP's remote-schema client issue does not establish exposure in this project's
fixed local client demonstration; the shipping servers use stdio. The reviewed
Pydantic advisory requires model configurations not found in the application.
The pins were still updated to the publishers' patched releases. Sources:
[MCP advisory](https://github.com/modelcontextprotocol/python-sdk/security/advisories/GHSA-rwrf-2pqf-9j8j)
and [Pydantic advisory](https://github.com/pydantic/pydantic/security/advisories/GHSA-qpmf-fgh3-ff25).

Source review and offline regression checks are distinct from a live security
assessment. Publisher accounts, deployment settings, arbitrary dependency
debug logs and an operating-system attacker controlling the configuration
directory were not tested. No publisher defenses were bypassed.

One EIA recording held an unredacted credential-shaped value in a nested
response field. The revised recorder discovers named credential fields
recursively and refuses surviving values. That helper redacted the existing
recording without replacing its publisher data. Fixture checks no longer
print values when they report a violation. Existing Git history was not
rewritten; ownership, validity and any needed rotation remain a maintainer
follow-up. No request tested the value.

DNS validation still precedes the HTTP client's connection resolution. The
registered-host restriction reduces the exposed surface, but this review does
not claim to have removed that resolve-to-connect race.

## Expansion order

First make the existing data easier to use correctly: a GCAM comparison
receipt, parameterized weather packages and explicit paper/dataset/software
relations. A model-driver evaluation matrix is a separate development project;
it compares agents, not GCAM assumptions.

Then add source classes required by a concrete workflow. Regulations.gov
dockets complement published Federal Register notices. PVWatts can support
modelled solar-production questions. ATB and interconnection-queue analysis
need edition-specific bulk readers. Each still needs its publisher-policy
review, recording plan and activation gates. An underfilled server profile is
a warning, not a reason to add filler tools or a mechanical activation blocker.

Do not add model execution, job submission, live queue-position claims or
observational claims from GCAM input tables. A hosted service remains a
separate operating-model decision.

## Follow-up correction, 2026-11-21

The earlier DNS limitation above is resolved by a transport that connects only
to the validated numeric addresses. The request retains its publisher Host
header, TLS hostname and certificate verification. Redirects obtain their own
validated address snapshots; concurrent requests keep separate snapshots.
Connection fallback shares the timeout among remaining addresses so a stalled
address cannot consume every alternative's budget. Environment proxies are
ignored because they would move DNS resolution outside this boundary.

The repository is public, and the historical EIA recording remains reachable
from its Git history. A value-only comparison found no matching current local
credential file or environment credential. This says nothing about ownership
or whether the value is still valid; no request tested it. The current file is
sanitized. Revocation by its owner comes first. Any later history rewrite and
cached-reference cleanup require a coordinated maintenance operation; neither
was performed during this assessment.

The follow-up suite contains 1,306 offline tests. The full replay run and the
focused DNS fallback regressions pass. Browser UAT again exercised all 38
walkthroughs at three widths, with no page errors or horizontal page overflow.
