# DOE-MCP

Read-only MCP servers for public DOE and national-laboratory data, with source evidence, coverage limits and recorded walkthroughs.

Independent project; not affiliated with the US Department of Energy.

## What the parts mean

- Server: a local MCP process that exposes a domain's tools.
- Tool: one typed, read-only operation returning data and provenance.
- Skill: a reusable capability-based workflow with recorded bench tasks.
- Application: a runnable workflow that combines tools and writes a local result bundle.
- Demo: a recorded example; it does not establish current publisher health.

The generated registry contains 10 shipping servers, 29 active sources and 32 scientific skills.
