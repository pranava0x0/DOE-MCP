November 3: what to take from other government-data MCPs

PR #6 added outage releases, NERSC status and microbiome records. PR #7 added recorded walks across those sources and the research catalogs. PR #8 put the walks on the landing page and marked the VIPS key requirement in the reference. A reader could already trace a record. Preparing a citation list or counting missing measurements still meant working through the JSON.

Server What its maintainers document Choice for DOE-MCP
US Census Bureau Its geography tool resolves names to candidate FIPS codes. Aggregate queries specify a dataset and vintage. Say exactly what a place filter selected. The NMDC query matches text containing “Washington”; it cannot establish a state boundary.
NASA Earthdata Separate tools find collections, check for granules and look up citations. Give readers citation fields they can take away. A catalog hit by itself says nothing about whether anyone read the paper.
cyanheads EIA server (community project) Its query results carry units and match totals. Its guide distinguishes null from zero. Keep numeric zero in the soil worksheet. Leave unreported values blank, name the unit and count missing fields only on the returned page.

This comparison covers documented workflows. It does not measure server uptime, response times or the accuracy of a model using them.

The bibliography worksheet applies the Genesis literature-search skill's bibliography step to DOE PAGES. The soil sample field check applies the data-exploration skill's missing-value check to NMDC. Neither runs the upstream scripts. Each worksheet row points to an evidence ID in the downloadable JSON. Both examples run from recordings without a model or key.
