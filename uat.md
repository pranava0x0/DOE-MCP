# Demo UAT

Last run: 2026-10-22.

The static site is generated by `tools/build_site.py --fixtures` from
`tools/render_site.py` and `tools/render_workflows.py`. Serve `docs/` over
HTTP. This run used `http://localhost:4192` and installed Google Chrome.

## Baseline flows

Run `NODE_PATH=<existing Playwright package directory> node tools/demo_uat.cjs`.
Set `UAT_URL` to use another local server. The script uses installed Chrome,
writes screenshots and results to ignored `uat-screenshots/`, and fails on
page overflow, hidden jump destinations, JavaScript errors or failed downloads.
No dependency installation is part of this check.

- Select every demo; exactly one article must be visible.
- Use every section button; focus must reach the section below the sticky controls.
- Check phone (375×812), tablet (768×1024) and desktop (1280×800).
- Open sample sources, download and parse JSON, and activate a jump with the keyboard.
- Load an unknown hash; the evidence demo must appear.

## Results

All 14 demos passed at all three sizes: 78 section jumps, no page overflow
and no JavaScript errors. The microbiome tables need no horizontal swipe.
JSON downloaded and parsed. Tab/Enter activated the Study jump.

| Task from a loaded microbiome demo | Before | After |
| --- | --- | --- |
| Reach the samples section | Scroll to a section 1,823 px below the viewport top | One tap, no swipe |
| Return to overview | Scroll back through preceding results | One tap |
| Change demo while reading samples | Scroll to the selector, then choose | Selector stays visible |
| Read wide sample metadata | Horizontal table movement could be needed | Labeled rows fit the phone |
| Inspect duplicate record-source cards | Cards always occupy the reading path | One tap on Record sources |

The scroll comparison uses measured section positions, not an assumed swipe
length. Native select interaction counts vary by operating system. This run
establishes improvements for these tasks, not a globally minimal interface.
Limits remain open and replay scope remains visible. Buttons wrap instead of
requiring horizontal swipes. No swipe-only controls were added.

## Performance

The generated HTML is 427,719 bytes, about 60 KB gzipped. It makes no external
font, script or data requests during page load. An inline empty favicon avoids
a failed favicon request. CPU-throttled local Chrome (4× slowdown) loaded in
37 ms, with DOM content ready in 19 ms; the section jump also succeeded.
These are single-run local diagnostics, not phone network or field metrics.
Network emulation did not affect localhost reliably, so no simulated mobile
network result is claimed. The static host must enable compression to obtain
the gzip transfer size; the local Python server does not.
